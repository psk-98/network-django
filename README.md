# Network

**Network** is a social media API built with Django, Django REST Framework (DRF), Cloudinary, and SQLite. It provides the backend for a social media platform, managing user interactions, posts, direct messages, notifications, profiles, and more.

## Features

- **Direct Messages**: Send and receive private messages between users.
- **Posts**: Create, read, update, and delete posts.
- **Following**: Follow and unfollow other users.
- **Notifications**: Receive notifications about important events and interactions.
- **Profile**: Manage user profiles, including updating profile information and viewing other users’ profiles.

## Tech Stack

- **Django**: A high-level Python web framework for building web applications.
- **Django REST Framework (DRF)**: A powerful toolkit for building Web APIs.
- **Cloudinary**: A cloud-based service for managing and storing media assets.
- **SQLite**: A lightweight database used for development and testing.
